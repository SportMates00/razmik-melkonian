YOUTUBE TITLES / VOCALIST NAMES
The Media page uses the public YouTube metadata endpoint via noembed.com to
display the exact current YouTube video title when the page loads. This means
vocalist/singer names included in the YouTube title are displayed automatically,
without guessing or hard-coding potentially incorrect names.
